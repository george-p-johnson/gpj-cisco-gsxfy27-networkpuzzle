Boards
Connecting…
  1. Wait for the status dot (top right) to read Connected, and the six Boards dots (top left) to be lit. If a board dot is dark, that player's panel isn't talking to the system yet — its Player button will show NO BOARDS and can't be turned on.
  2. Turn on the players who are playing this round by tapping their button: Player 1 (Green), Player 2 (Navy), Player 3 (Teal). A player turns green/highlighted when active; tap again to turn them off. At least one player must be on to start.
  3. If the yellow "Unplug all patch cords…" banner appears, it means the system still sees a patch cable connected from the previous round. Usually this just clears itself once the cables are actually removed. Start Game only becomes disabled if several cables are still detected at once — an occasional single warning (especially on Player 1's first socket) can be a harmless sensor quirk and doesn't need troubleshooting on its own.
  4. Tap Start Game. The Game State will count down (Three → Two → One → Start) and then move into Gameplay.
  5. During Gameplay, each active player's button updates live as they finish — WINNER, 2ND PLACE, 3RD PLACE, or TRY AGAIN if they don't finish in time. Results stay visible during the Results state.
  6. Tap Reset Game to return to Idle and prep for the next round. This automatically re-activates any player whose boards are online, so you'll typically just need to confirm the right players are on before starting again.
  7. Use Show Answer Key below to look up the correct answer for any question if a player needs help or a ruling.
